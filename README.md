# Memory Flash Game

Memory Flash is a browser-based game designed to test and improve short-term memory and concentration. The player watches a sequence of flashing colored tiles and then repeats the sequence in the correct order.

As the player progresses, the sequences become longer and more challenging, requiring greater focus and memory retention.

## 🎮 How to Play
1. Click **Start Game**
2. Watch the sequence of flashing tiles carefully
3. Repeat the sequence by clicking the tiles in the same order
4. Advance to higher levels as long as you are correct
5. The game ends if you make a mistake

## ✨ Features
- Random sequence generation (no predictable patterns)
- Increasing difficulty with each level
- Visual and audio feedback
- High score tracking (stored locally)
- Background music with mute option
